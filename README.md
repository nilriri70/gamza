# 🥔 감자 마켓 (Gamza Market)

포근한 우리 동네 중고 거래 웹 서비스 **감자 마켓(Gamza)** 프로젝트입니다.

## ✨ 주요 기능
1. **상품 목록 및 실시간 필터링 (`화면 1`)**
   - 카테고리별(전체, 디지털기기, 가구/인테리어, 의류, 생활가전, 도서/티켓, 기타) 필터링
   - 검색어(상품명, 동네, 설명, 판매자 닉네임) 실시간 검색
   - **'거래 가능만 보기'** 토글 스위치 (`거래 완료` 상품 자동 제외 및 흐림 표시)
2. **상품 상세 모달 및 작성자 전용 관리 (`화면 2`)**
   - 판매자 프로필(닉네임, 아바타, 활동 동네) 및 상세 정보 표시
   - **내가 쓴 글 관리**: 작성자 본인 클릭 시 `판매중` / `예약중` / `거래 완료` 상태 즉시 변경 및 `수정` / `삭제` 기능 제공
3. **상품 등록 및 수정 (`화면 3`)**
   - 상품 사진 업로드(`Supabase Storage` 연동) 및 카테고리별 감자 일러스트 프리셋 제공
   - 비로그인 상태에서 `[글쓰기]` 클릭 시 로그인 모달 선행 후 글쓰기 화면 자동 연결
4. **회원가입 및 로그인 (`Supabase Auth`)**
   - 이메일 · 비밀번호 · **닉네임(필수)** 기반 회원가입 및 로그인 모달
   - 개인 식별 정보(PII)를 공개 테이블(`public.profiles`, `public.products`)에 저장하지 않는 안전한 구조

## 🛠️ 기술 스택
- **Frontend**: HTML5 (`<dialog closedby="any">`), CSS3, Vanilla JavaScript (ES6+)
- **Backend / BaaS**: Supabase (`Database`, `Auth`, `Storage`, `Row Level Security`)

## 🚀 실행 방법
별도의 빌드 과정 없이 정적 웹 서버(GitHub Pages, Vercel, Netlify, Live Server 등)에 배포하거나 `index.html`을 브라우저에서 열어 바로 실행할 수 있습니다.
